# Data sources and attribution

The original Word reports cite the **UCI Machine Learning Repository**. The raw datasets were **not committed** to the original GitHub repository.

| Historical study | Source dataset | UCI source |
|---|---|---|
| Supervised | Echocardiogram (UCI ID 38) | https://archive.ics.uci.edu/dataset/38/echocardiogram |
| Unsupervised | Absenteeism at Work (UCI ID 445) | https://archive.ics.uci.edu/dataset/445/absenteeism%2Bat%2Bwork |

The dataset pages provide source attribution, field descriptions, and reuse guidance. Their current versions may not be identical to the specific historic files used in the coursework. A modern reproduction must track dataset revision, download date, hashes, feature definitions, missing-value conventions and exact preprocessing.

The new [synthetic examples](../examples/synthetic_demo.py) **generate artificial data** using scikit-learn; they do not download or distribute clinical or personnel records. Always credit source dataset creators and respect their licensing and ethical restrictions.
